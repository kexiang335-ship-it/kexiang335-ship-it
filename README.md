# 邵柯翔个人简历与项目档案

这是一个无需构建工具、可直接部署到静态托管的个人作品网站。

## 页面层级

- `index.html`：第一层个人主页，包含定位、公司持股、AI 视觉临床诊断研究方向、项目经历、AI 成长时间轴、方法论、证书与实践证明。
- `portfolio.html`：第二层作品集仓库，最新项目优先；保留原有四张项目经历卡片。
- `project-detail.html#项目标识`：第三层项目详情（例如 `#tcm`、`#couple`、`#ruivision`、`#plugin`、`#redwood`），详情页可继续跳转原项目体验。

## 已整理内容

- 中医学习网、小鱼小邵情侣微信小程序、RuiVision 电商工作台、1688 选品插件、红木 3D 网站列为最新项目。
- 南京锐维智创科技有限公司（20%，非法人）与南京市瑞雨山科技有限公司（11%，非法人）。
- GitHub：<https://github.com/kexiang335-ship-it>（当前公开仓库信息以 GitHub 页面为准）。
- `assets/evidence/` 保存用户提供的两张证书和两张美团实践证明，页面点击可放大查看。
- `assets/project-shots/` 保存 AI 外贸、RPA、宠物医疗知识库三个本地项目的浏览器实拍缩略图。
- 首页新增“专业与 AI 研究方向”板块，整理了公开资料里的 AI 视觉临床诊断思路，并补充“人在回路”和“行业 + AI”的表达。

## 本地预览

在项目目录运行 `python -m http.server 4173`，然后打开 <http://127.0.0.1:4173/>。

站点使用原生 HTML/CSS/JavaScript，包含响应式布局、项目筛选、滚动进度、滚动显现动效、证书大图弹层、复制联系方式和中英切换；支持 `prefers-reduced-motion` 降级。

最近一轮浏览器验收已经检查了首页研究板块、语言切换和医疗筛选卡片的显示状态。
