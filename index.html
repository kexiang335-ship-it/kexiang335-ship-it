05 / HOW I WORK

我的学习与交付方法

把“学会了”变成“下次还能用”，靠的是固定节奏。

01 / INPUT

先研究，再动手

先看官方文档、真实案例和限制条件，记录来源；不把模型的第一句话当结论。

02 / LOOP

小步构建，马上验证

把大目标拆成可运行的小闭环，每完成一段就用真实数据、浏览器和用户路径验证。

03 / MEMORY

复盘并沉淀资产

保存提示词、决策、失败原因和截图，把一次项目变成下一次的模板、组件或 SOP。

06 / CREDENTIALS

证书与实践证明

点击图片查看大图。证书文字按原件整理，图片仅作展示与佐证。
